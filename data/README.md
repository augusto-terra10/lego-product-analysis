# Data

This folder contains the supplied source dataset and its field dictionary.

- `lego_sets.csv` – 18,457 product records and 14 source fields.
- `lego_sets_data_dictionary.csv` – descriptions of the original source fields.

The source dataset includes missing values. These are retained as missing rather than being automatically replaced with zero. The Power BI report adds analytical classifications, including Portfolio Product Group, Age Range and Price Range.

See [Data quality considerations](../README.md#data-quality-considerations) in the main README.
