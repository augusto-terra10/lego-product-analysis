# Measures Catalogue

The following measures are sample calculations used in the analysis. For further details on all measures created, please refer to the dashboard file.

| Measure | Report use |
|---|---|
| `Total Products` | Product count KPI, theme ranking, release-year trend and decomposition tree analysis. |
| `Avg Pieces per Product` | KPI showing the average available piece count per product. |
| `Avg Recorded Price (USD)` | KPI and theme-level average recorded retail price comparison. |
| `Priced Products` | Count of products represented in the price distribution. |
| `Sum Prices` | Supporting price aggregation referenced by a Collection Insights visual tooltip. |
| `Selected Product` | Selected-product detail panel. |
| `Selected Pieces` | Selected-product piece-count detail. |
| `Selected Price` | Selected-product price detail. |
| `Selected Year` | Selected-product release-year detail. |
| `Selected Ages` | Selected-product age detail. |
