# Project Overview

## Purpose

The LEGO Product Portfolio Analysis project provides an interactive way to search, explore and analyse a catalogue of LEGO products. It combines a product-level finder, a hierarchical decomposition tree and a portfolio insights page.

## Report pages

### LEGO Set Finder

Supports product discovery through a table, slicers, a numeric price filter and a selected-product detail panel. The panel is designed to show product information and an image where the source image URL is available.

### Product Explorer

Uses a Power BI decomposition tree to explore the total product count through Portfolio Product Group, Theme, Subtheme and Product Name.

### Collection Insights

Provides portfolio-level views of product counts, recorded prices, release history, price bands and the relationship between retail price and piece count.

## Analytical scope

The report explores product catalogue composition and the available source price and product attributes. It is descriptive analysis; it does not estimate current market value, resale value or product demand.

## Important limitations

The source dataset contains missing values in fields such as price, piece count, minimum age, minifigures and subtheme. Measures based on these fields should be interpreted using the available records only. The reported average retail price is an average of recorded launch prices, not a current market price.
